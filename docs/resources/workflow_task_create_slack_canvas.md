# Resource (rootly_workflow_task_create_slack_canvas)

Configures an action that creates an incident channel Canvas. Terraform manages the workflow action configuration; the action writes to Slack when its workflow runs. Your organization needs access to Rootly's Slack Canvas workflow actions and a Slack integration with the required Canvas permissions.

The example starts with both the workflow and action disabled. Replace the workspace values with your Slack workspace, then enable the workflow and action when ready. The optional `channel.workspace` block selects the workspace for an Enterprise Slack installation. Omit it for a regular workspace installation. Removing a previously configured workspace block clears that selection.

The workflow runs after its incident Slack channel is created. Creating a Canvas preserves an existing channel Canvas.

## Example Usage

```terraform
resource "rootly_workflow_incident" "canvas" {
  name    = "Slack Canvas report"
  enabled = false

  trigger_params {
    triggers = ["slack_channel_created"]
  }
}

resource "rootly_workflow_task_create_slack_canvas" "report" {
  workflow_id = rootly_workflow_incident.canvas.id
  name        = "Create incident Canvas"
  enabled     = false
  position    = 1

  task_params {
    title = "Incident {{ incident.sequential_id }}: {{ incident.title }}"
    channel {
      id   = "{{ incident.slack_channel_id }}"
      name = "Incident channel"

      workspace {
        id   = "T0123456789"
        name = "Engineering"
      }
    }
    content = <<-MARKDOWN
      # Incident update

      **Summary:** {{ incident.summary }}
    MARKDOWN
  }
}
```
